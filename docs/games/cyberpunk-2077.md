# Cyberpunk 2077

1. Run `./install.sh` and select `bin/x64/Cyberpunk2077.exe`.
2. Choose the Proton runner already used by the game and the **native FSR** route.
3. Keep your current Steam options through the installer, then copy its complete final line.
4. Select **FSR 3/4** in the game. **End** opens DLSS-NR.

OptiScaler is not needed for this route. Keep your preferred Quality or Balanced
mode. Path tracing is a separate game setting; this mod neither adds nor requires it.
