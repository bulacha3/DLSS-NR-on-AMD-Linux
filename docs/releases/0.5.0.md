# 0.5.0 — Linux / Proton

Experimental Linux/Proton integration of **DLSS-NR on AMD 0.5.0**, checked in
Cyberpunk 2077, 007 First Light and Atomic Heart on RX 9070 XT.

## Changes

**Upstream:** richer neural-rendering output, especially skin and faces, plus
setup and settings-editor improvements. The upstream author reports up to **207%**
better RX 7000/RDNA3 performance and **5%** better RX 9000/RDNA4 performance versus
0.4.3. These are the author's measurements, not verified Linux FPS gains.
[Original upstream notes](https://github.com/danielblnc/DLSS-NR-on-AMD/releases/tag/v0.5.0).

**Linux installer:** Python **3.10+** is now accepted for the original runtime
path. Setup checks Python environment prerequisites before an optional HIP
download, reports the failing stage, shows the exact hidden mod-folder location,
and does not print a launch command for an invalid installation or dry run.
The installation guide now explains Mint/Ubuntu, SteamOS and Steam Flatpak
prerequisites without implying that every GPU on those systems is supported.

The existing priority-stream synchronization and guided five-step installer are
retained. Updating preserves model data, visual settings, custom overlay keys and
original-file backups. No new experimental inference path is enabled.

## Linux performance observations versus 0.4.3

### Cyberpunk 2077 — built-in benchmark averages

| FSR mode | 0.4.3 average | 0.5.0 average | Change |
| --- | ---: | ---: | ---: |
| Quality | 55.22 FPS | 55.92 FPS | **+1.27%** |
| Balanced | 64.87 FPS | 65.87 FPS | **+1.54%** |

One run per mode and version, with the same reported settings: Cyberpunk 2.31,
3612 × 1512, High textures, RT lighting Ultra, path tracing off, FSR 4 with frame
generation on, VSync and FPS limit off. RX 9070 XT / Ryzen 9 9950X3D on Linux/Proton;
DLSS-NR Fast. New-run minimum/maximum: **52.49–62.29 FPS Quality** and
**61.38–72.61 FPS Balanced**. No repeatability estimate was measured, so changes
this small may include run-to-run variation. These are not native-rendered FPS.

### 007 First Light and Atomic Heart — observed gameplay ranges

These are **observed minima and maxima**, not benchmark means or 1% lows.
Scenes and sampling duration were not controlled between versions. The two
percentage columns compare the corresponding range endpoints only; they must
not be read as overall performance gains.

| Game / FSR mode | 0.4.3 observed range | 0.5.0 observed range | Minimum change | Maximum change |
| --- | ---: | ---: | ---: | ---: |
| 007 First Light / Quality | 42–47 FPS | 42–50 FPS | 0.00% | +6.38% |
| 007 First Light / Balanced | 47–54 FPS | 50–55 FPS | +6.38% | +1.85% |
| Atomic Heart / Quality | 37–44 FPS | 38–46 FPS | +2.70% | +4.55% |
| Atomic Heart / Balanced | 22–55 FPS | 45–56 FPS | +104.55%* | +1.82% |

Both games used 3440 × 1440 and DLSS-NR Fast through OptiScaler; the loaded FSR
versions were **4.1.1 in 007** and **3.1.4 in Atomic Heart**. Frame-generation
configuration outside the NR counters is not established here, so these ranges
are not advertised as native-rendered FPS.

\* The previous Atomic Heart Balanced session included a **22 FPS minimum with
an unknown cause**. Its change to 45 FPS is +104.55% arithmetically, **not evidence
that average performance doubled or that a stutter problem was fixed**.

All percentages use `(new / old - 1) × 100`. The baseline is the
[previous release's reported results](0.4.3.md#performance-observations).
No midpoint of a range is treated as a measured average. Results are observations
on one system, not guarantees for other hardware or configurations.

## Install or update

Download **`dlssnr-linux-portable.zip`** and its **`.zip.sha256`** file from Assets.
Close the game, extract into a new directory and run **`./install.sh`** as your
normal user, without sudo. Follow the five steps and copy the complete final
command into that game's Steam launch options. Install separately for each game.

**Where is the mod folder?** The installer creates **`.dlssnr-linux` beside the
selected game executable**, not necessarily in the game's top-level directory.
The leading dot hides it; use **Ctrl+H** or **Show Hidden Files**. The Steam command
only launches the installed mod; it does not install it. Do not create an empty
folder manually.

[Installation guide](../INSTALL.md#where-the-mod-is-installed) ·
[Missing-folder troubleshooting](../TROUBLESHOOTING.md#mod-folder-is-missing).

## Coverage and limitations

Startup, gameplay, overlay access and Quality/Balanced resource changes were
checked in the three games on **RX 9070 XT / gfx1201, with Fast arithmetic**.
The latest supplied logs contain **32,125 corresponding ordered handoffs and
completions**; all **178 periodic summaries** report zero skipped jobs/timeouts.
These checks are not a full numerical or visual equivalence certification.

**Intermittent processing spikes remain unresolved:** the Cyberpunk session
recorded 24 jobs taking 101–120 ms. No equivalent spike record appeared in the two
other supplied sessions; that does not establish stutter-free operation.

Other GPUs (including RDNA3 performance), SteamOS/Mint gameplay, Reference-mode
gameplay, fresh model extraction and long-duration stability have not been
validated for this release. GPU targets remain unchanged; SteamOS support is not
equivalent to Steam Deck/RDNA2 support. Documentation improvements do not, by
themselves, resolve an individual installation report.

The ZIP contains the installer, bridge components, matching sources and licenses.
It does not include personal session logs, benchmark collectors, experimental GPU
modules, NVIDIA model files/weights or AMD runtime/compiler libraries.
