# 0.4.3 — Linux / Proton

Experimental Linux integration of the original **DLSS-NR on AMD 0.4.3** runtime.

## Changes

- Update to upstream 0.4.3, including its inference performance improvements,
  configurable `OverlayKey`, and overlay/settings-editor fixes.
- Retain the Linux priority-stream synchronization fix and the complete guided
  installer for Steam and other launchers.
- Preserve existing model data, visual settings, custom overlay keys and
  original-file backups when updating.

Optional lmxxf optimizations are selected per release when they provide a verified benefit. Version 0.4.3 uses the original upstream inference backend.

## Install or update

Download `dlssnr-linux-portable.zip` and its `.sha256` file from the release
assets. Close the game, extract into a new directory, and run **`./install.sh`**.
Follow all five guided steps and copy the complete final launch command.
Do not use an older launcher command or replace individual DLLs manually.

[Full installation guide](../INSTALL.md).

## Coverage and limitations

**Cyberpunk 2077:** startup, gameplay, overlay and FSR Quality/Balanced switching
checked on RX 9070 XT through Proton, using DLSS-NR Fast, FSR 4.1.1 and frame generation.

**007 First Light and Atomic Heart:** startup, gameplay and Quality/Balanced
switching checked on RX 9070 XT through Proton with DLSS-NR Fast and OptiScaler.
The loaded FSR versions were 4.1.1 in 007 and 3.1.4 in Atomic Heart.
Other hardware, Reference-mode gameplay, fresh model extraction and long-duration
stability remain unverified in this release.
Intermittent processing spikes remain unresolved.

### Performance observations

| Game / measurement | Quality | Balanced |
| --- | ---: | ---: |
| Cyberpunk 2077, built-in benchmark average | 55.22 FPS | 64.87 FPS |
| 007 First Light, observed gameplay range | 42-47 FPS | 47-54 FPS |
| Atomic Heart, observed gameplay minimum-maximum | 37-44 FPS | 22-55 FPS |

Cyberpunk 2.31: 3612 x 1512, High textures, RT lighting Ultra, path tracing off,
FSR 4 and frame generation on, VSync and FPS limit off. One run per mode on
RX 9070 XT / Ryzen 9 9950X3D. These are not native-rendered frame rates.
007 and Atomic Heart used 3440 x 1440; their ranges are user observations, not
benchmark averages or matched scenes. The Atomic Heart Balanced minimum of
22 FPS is retained; its cause has not been established. These results do not
measure a version-to-version improvement or guarantee performance elsewhere.

Upstream performance percentages describe the author's measurements, not a
verified Linux FPS gain. Results vary with the game and configuration.

The package includes the installer, bridge components, corresponding sources
and license notices. It does not include personal session logs, benchmark
collectors, experimental inference modules, NVIDIA files or model weights.
